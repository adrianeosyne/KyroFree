Kyro is now available for Android 10 and newer.

- Sign in with your existing Kyro account.
- A redesigned mobile interface for chats, friends and communities.
- Android Back navigation, file uploads, HTTPS downloads, microphone and camera permissions.
- Deep links for Kyro communities and Premium gifts.
- Connection retry and safe spacing around the keyboard and system bars.

Download `Kyro-Android-1.0.0.apk` and open it to install. Allow your browser to
install Kyro if Android asks. `Kyro-Android-1.0.0.aab` is the signed Android App
Bundle for future store distribution, not a file to install directly. SHA-256
checksums are included in `SHA256SUMS.txt`.

Complete source for this release:
https://github.com/adrianeosyne/KyroFree/tree/android-v1.0.0/mobile/android

Shared web UI and backend source:
https://github.com/adrianeosyne/KyroFree/tree/android-v1.0.0/src

This release needs an internet connection. Calls operate while the app is in
the foreground; background calling, push notifications and screen sharing
are not included. Camera and microphone access are requested when needed.
