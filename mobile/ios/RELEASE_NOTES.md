# Kyro for iOS 1.0.0

Native iPhone and iPad client for iOS 16 and newer, using the same Kyro account,
chats, communities and hosted services as Android and Windows.

- Native navigation, reload, link sharing and browser handoff.
- Persistent WebKit login storage, system attachment pickers and file sharing.
- Camera and microphone permission prompts for foreground calls.
- Loading and connection recovery interfaces, with restricted in-app origins.
- Complete Swift source, Xcode project, unit tests and simulator UI tests.

[Download the source project](https://github.com/adrianeosyne/KyroFree/releases/download/ios-v1.0.0/Kyro-iOS-1.0.0-source.zip)
or [view the source](https://github.com/adrianeosyne/KyroFree/tree/main/mobile/ios).
The release includes the source ZIP with its license, simulator app, unsigned
device archive and checksums. Use a Mac, Xcode and a free Apple ID Personal Team
to build and install on your own iPhone or iPad with automatic signing. See the
[free build guide](README.md). Free provisioning lasts about seven days and can
be renewed by running from Xcode again. The ZIP and unsigned archive are not
directly installable iPhone apps. Background calling, push notifications and
screen sharing are not included in this version.
